# Trilha sonora local em OGG

Coloque nesta pasta os arquivos convertidos, preservando exatamente maiúsculas, minúsculas e extensão:

| Cenário | Referência informada | Arquivo esperado |
|---|---|---|
| Floresta dos Números | *Ninja Spirit* — “Level 2 - Forest” | `NinjaForest.ogg` |
| Deserto das Operações | *Soldier Blade* — “Operation 1 - Raid on Zeograd Forces” | `T_SoldierBlade_Track03.ogg` |
| Montanhas da Lógica | *The Legendary Axe* — “Zone 1” | `Zone1-MG.ogg` |
| Cidade das Expressões | *City Hunter (Japan)* — “Stage 1” | `City_Hunter_Level_1.ogg` |
| Cosmos Matemático | *Salamander (Japan)* — “Level 2 - Meteorite Space” | `salalvl2.ogg` |

OGG é reproduzido nativamente por Chrome, Edge e navegadores Chromium, sem sintetizador, base64 ou etapa de conversão durante o build. Exporte com qualidade adequada para música (por exemplo, Vorbis entre 128 e 192 kbit/s), confira loop e volume antes da distribuição.

Os arquivos não fazem parte desta cópia do repositório. Confirme que você possui autorização para convertê-los, utilizá-los e redistribuí-los. Se um arquivo estiver ausente ou inválido, o jogo continua normalmente e não mostra mensagens de erro ao estudante; a criação do instalador, porém, exige as cinco faixas para evitar um pacote incompleto.
