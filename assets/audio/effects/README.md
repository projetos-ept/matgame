# Design de som opcional

Adicione os efeitos em **OGG Vorbis** com exatamente estes nomes:

| Evento | Arquivo |
|---|---|
| Música em loop na tela inicial | `musica_abertura.ogg` |
| Encerramento por tempo ou queda | `game_over.ogg` |
| Clique em botões de menu/painéis | `clique_menu.ogg` |
| Pulo normal do personagem | `pulo.ogg` |
| Coleta da estrela de poder | `coletar_estrela.ogg` |
| Rajada de fogo do dragão | `dragao_tiro_fogo.ogg` |
| Lançamento do bumerangue | `bumerangue_lancamento.ogg` |
| Entrada do Guardião da Incógnita | `boss_aparece.ogg` |
| Disparo do Guardião | `boss_tiro.ogg` |
| Entrada do gigante e aviso “PULE!” | `gigante_pule.ogg` |
| Resposta matemática correta | `resposta_correta.ogg` |
| Alternativa errada | `resposta_errada.ogg` |
| Aparição de fantasma | `fantasma_aparece.ogg` |

Todos são opcionais: arquivo ausente, inválido ou reprodução bloqueada não mostra erro e não interrompe o jogo. Evite normalização muito alta; efeitos simultâneos devem permanecer confortáveis. Confirme licença e registre a origem em `CREDITS.md` antes de distribuir.
